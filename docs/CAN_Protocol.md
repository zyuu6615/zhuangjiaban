# Touch_led CAN 通信协议

本文档描述 STM32F103（触控灯板）与上位机之间的 CAN 通信协议，供上位机开发对接。

## 总线参数

| 项目 | 值 |
|------|----|
| 波特率 | **500 kbps** |
| 帧格式 | 标准帧（11 位标准 ID，`CAN_ID_STD`） |
| 字节序 | **小端**（Little-Endian，低字节在前） |
| 位时序（参考） | Prescaler=4, BS1=15TQ, BS2=2TQ, SJW=2TQ，采样点 88.9% |

> 上位机的 USB-CAN / TTL-CAN 适配器必须设为 **500 kbps** 才能正常收发。

## 报文总览

| 方向 | 名称 | CAN ID | DLC | 说明 |
|------|------|--------|-----|------|
| MCU → 上位机 | 状态上报 | `0x100` | 5 | 灯状态 + 振动计数，状态变化时发送 |
| 上位机 → MCU | 颜色控制 | `0x200` | ≥1 | 远程设置灯颜色 |

---

## 1. 状态上报帧（MCU → 上位机，ID = 0x100）

MCU 在 **灯颜色变化** 或 **振动计数变化** 时主动发送一帧。

| 字节 | 名称 | 类型 | 说明 |
|------|------|------|------|
| data[0] | 灯状态 | uint8 | `0`=熄灭 `1`=红 `2`=蓝 |
| data[1] | 振动计数 bit0-7 | uint8 | 计数（uint32）低字节 |
| data[2] | 振动计数 bit8-15 | uint8 | |
| data[3] | 振动计数 bit16-23 | uint8 | |
| data[4] | 振动计数 bit24-31 | uint8 | 高字节 |

**解析（小端）**：

```
led_state = data[0];
vib_count = data[1] | (data[2] << 8) | (data[3] << 16) | (data[4] << 24);
```

**示例**：`ID=0x100  DLC=5  data=[01 2A 00 00 00]`
→ 灯为红色，振动计数 = 0x0000002A = 42 次。

> 说明：`data[0]` 可能出现 `0xFF`——表示开机后尚未拨动过本地开关时的「未知」状态，上位机可将其显示为“未知/未初始化”。

---

## 2. 颜色控制帧（上位机 → MCU，ID = 0x200）

上位机发送该帧远程切换灯颜色。

| 字节 | 名称 | 类型 | 说明 |
|------|------|------|------|
| data[0] | 目标颜色 | uint8 | `0`=熄灭 `1`=红 `2`=蓝 |

- DLC ≥ 1；`data[0]` 之外的字节忽略。
- `data[0] > 2` 的帧会被 MCU 丢弃（不改变状态）。

**示例**：

| 目标 | 报文 |
|------|------|
| 变红 | `ID=0x200  DLC=1  data=[01]` |
| 变蓝 | `ID=0x200  DLC=1  data=[02]` |
| 熄灭 | `ID=0x200  DLC=1  data=[00]` |

MCU 执行命令后会立即回发一帧 `0x100` 状态上报，上位机可据此确认命令生效。

---

## 3. 本地开关与远程命令的仲裁：最后操作优先

灯颜色有两个控制源，采用 **最后操作优先（last-command-wins）**：

- 拨动本地开关 → 本地命令生效；
- 上位机发 `0x200` → 远程命令生效；
- 谁最后动，谁说了算。远程设色后，只要本地开关没再拨动，就不会被覆盖回去。

因此上位机无需担心与本地开关“抢控制”——两者是对等的事件源。

---

## 附：Python（python-can）示例

```python
import can

bus = can.interface.Bus(channel='COM3', bustype='slcan', bitrate=500000)

# 发送：把灯设为红色
bus.send(can.Message(arbitration_id=0x200, is_extended_id=False, data=[0x01]))

# 接收：解析状态上报
for msg in bus:
    if msg.arbitration_id == 0x100 and msg.dlc >= 5:
        led = msg.data[0]
        vib = int.from_bytes(msg.data[1:5], 'little')
        print(f'灯状态={led}  振动计数={vib}')
```
